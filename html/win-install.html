Install ShapeIt for Windows

Zwei einfache Wege, ShapeIt unter Windows auszuprobieren: als ZIP-Datei ohne Installer oder als klassische Setup-Installation.

Two simple ways to try ShapeIt on Windows: as a ZIP file without an installer, or as a classic setup installation.

Welche Variante soll ich nehmen?

Wenn du ShapeIt nur testen möchtest oder nichts installieren willst, ist die ZIP-Datei meist die beste Wahl. Wenn du lieber eine normale Windows-Installation mit Startmenü-Eintrag möchtest, nimm das Setup.

Which option should I choose?

If you only want to try ShapeIt, or if you do not want to install anything, the ZIP file is usually the best choice. If you prefer a normal Windows installation with a Start menu entry, choose the setup installer.

Option 1 · ohne Installation

ZIP-Datei herunterladen

Lade das Archiv herunter, entpacke es in ein Verzeichnis deiner Wahl und starte anschließend ShapeIt.exe.

  1. ZIP-Datei herunterladen.
  2. In einen Ordner entpacken, zum Beispiel unter Dokumente\ShapeIt.
  3. ShapeIt.exe starten.
⬇️ shapeit-win-x64.zip herunterladen
Option 2 · Windows-Setup

Installation starten

Starte das Setup-Programm und folge den Anweisungen des Installers.

  1. Setup-Datei herunterladen oder direkt starten.
  2. Windows-Sicherheitsabfrage bestätigen, falls sie erscheint.
  3. Nach der Installation ShapeIt über das Startmenü oder die Verknüpfung starten.
▶️ shapeit-setup.exe starten
Option 1 · no installation

Download ZIP file

Download the archive, unpack it into a folder of your choice, and then start ShapeIt.exe.

  1. Download the ZIP file.
  2. Unpack it into a folder, for example Documents\ShapeIt.
  3. Start ShapeIt.exe.
⬇️ Download shapeit-win-x64.zip
Option 2 · Windows setup

Start installation

Start the setup program and follow the installer instructions.

  1. Download or start the setup file.
  2. Confirm the Windows security prompt if it appears.
  3. After installation, start ShapeIt from the Start menu or the desktop shortcut.
▶️ Start shapeit-setup.exe

Hinweis

Beim ersten Start kann Windows eine Sicherheitswarnung anzeigen, weil ShapeIt ein Open-Source-Projekt ist und die Datei möglicherweise noch nicht allgemein bekannt ist. Klicke dann auf "Weitere Informationen" und dann "Trotzdem ausführen".

Note

On first start, Windows may show a security warning because ShapeIt is an open-source project and the file may not yet be widely recognized. In that case, click "More information" and then "Run anyway".
